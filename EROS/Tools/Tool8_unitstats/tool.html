How the Calculation Works

The calculator reproduces the client formula with 32-bit float rounding. Class and rarity describe the unit but do not directly multiply core stats.

truncate((base + pow(level * multiplier / 100, exponent / 100 + rankModifier * level / 1000) - 1) * modifier + rank * 10 + flat)
