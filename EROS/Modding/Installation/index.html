Step by step

Manual installation

Keep the game closed while copying or replacing files.

01

Open the game folder

In Steam, open the game properties and browse the installed files. The correct folder contains the game executable.

Steam → Properties → Installed Files → Browse
02

Download BepInEx

Use the official installation guide to choose the build that matches the game and your operating system.

Open official guide
03

Extract into the game root

Open the downloaded archive and copy its contents beside the game executable, not into a separate nested folder.

Game folder / BepInEx / ...
04

Run the game once

Start the game, wait for the main menu, then close it. BepInEx creates its configuration, log, and plugins folders.

Check for BepInEx/LogOutput.log
05

Add the Mod Manager

Download the latest ModManager.dll release and place it in the BepInEx plugins folder.

BepInEx/plugins/ModManager.dll
06

Confirm and add mods

Launch the game and look for Mod Manager in settings. Once it appears, you are ready to install supported mods.

Browse the mod list
Before troubleshooting

Confirm that the files are in the game root, run the game once, and check BepInEx/LogOutput.log for loader or plugin errors.
